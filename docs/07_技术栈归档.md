## 1. 文档概述

### 1.1 目的

本文档归档超短波监测管理一体化服务系统涉及的所有技术栈，为技术选型、团队培训、项目交接提供统一的参考依据。

### 1.2 范围

本文档涵盖以下技术领域：
- 后端服务框架
- 核心开发语言
- 数据库与缓存
- 通信协议
- 网络与I/O库
- 日志与监控
- 构建与部署

## 6. 通信协议技术栈

### 6.1 协议层次

```
┌─────────────────────────────────────────────┐
│         应用层协议                           │
│  ┌─────────────┐  ┌─────────────────────┐  │
│  │ SOAP/XML   │  │ 自定义二进制(RMCPTP) │  │
│  └─────────────┘  └─────────────────────┘  │
├─────────────────────────────────────────────┤
│         传输层协议                           │
│  ┌─────────────┐  ┌─────────────────────┐  │
│  │ HTTP/HTTPS │  │ TCP/IP (设备通信)    │  │
│  └─────────────┘  └─────────────────────┘  │
└─────────────────────────────────────────────┘
```

### 6.2 协议详情

| 协议 | 类型 | 版本 | 说明 |
|------|------|------|------|
| **SOAP** | XML Web服务 | 1.1 / 1.2 | 客户端与服务通信 |
| **RX-RMCPTP** | 二进制协议 | 2.0 | 服务与设备通信 |
| **HTTP** | Web协议 | 1.1 / 2.0 | 传输层 |
| **TCP/IP** | 网络协议 | IPv4/IPv6 | 底层传输 |

### 6.3 自定义协议

|----------|------|------|--------|

# SpecDetect_Atom 重构计划

**日期**: 2026-04-23
**版本**: 1.0
**状态**: 规划中

---

## 背景

SpecDetect_Atom 是模拟 RXAtom 设备的服务，目前 FSCAN 接口已实现端到端推送（30秒持续推送，VER=1 对齐），但 PScan/MSCAN/SglFreqMeas 接口的 RMCP 回调解析和 streamsrc 帧生成尚未完成。

**问题核心**: 当前 `parse_fscan_payload` 和 `build_fscan_frame` 是 FSCAN 专用实现，不同接口的 RMCP 回调帧结构不同，需要统一的解析/分派框架。

---

## 终极目标

**SpecDetect_Atom 服务可运行，与 Real Atom 行为一致**

---

## 核心架构

```
SOAP Client (PC)
    ↓ SOAP请求
soap_proxy / atom/service.py
    ↓ RMCP请求
rmcp_proxy (透明代理)
    ↓
Real Atom / Emulated Atom
    ↓ RMCP回调 (n_bd_type, payload)
parse_rmcp_payload(n_bd_type, payload) → band_info
    ↓
build_stream_frame(n_bd_type, band_info) → bytes
    ↓ streamsrc推送
streamsrc Client (PC)
```

---

## P0 - 统一 RMCP 解析与 streamsrc 帧生成框架

### 问题分析

当前实现的问题：
1. `parse_fscan_payload` 只支持 FSCAN (n_bd_type=15) 和 SGLFREQ (n_bd_type=0x0E)
2. 不同 n_bd_type 的 payload 结构不同（counters offset、数据点数、编码方式）
3. streamsrc 帧生成函数分立实现，无统一分派入口

### RMCP Payload 解析

| n_bd_type | 接口 | payload 结构 | 数据点数 | counters offset | 编码 | 状态 |
|-----------|------|------------|---------|----------------|------|------|
| 15 | B_FScan | `[n_bd_type][2B][counters(8B)][int16[N]]` | 512/417 | offset=3 | int16 | ✅ 已验证 |
| 0x0E | B_MScan/B_SglFreqMeas | `[n_bd_type][counters(8B)][int16]` | 1 | offset=1 | int16 | ✅ 已验证 |
| 0x0B | B_SglFreqMeas | `[n_bd_type][2B][counters(8B)][int16[N]]` | 605? | offset=3? | int16? | ⬜ |
| 0x10 | B_PScan | `[n_bd_type][2B][counters(8B)][int16[N]]` | 605 | offset=3 | int16 | ✅ 实测 |
| 0x10 | B_FScan(附) | `[n_bd_type][2B][counters(8B)][int16[N]]` | 605 | offset=3 | int16 | ⬜ 暂不处理 |

**任务 P0-1**: 创建 `parse_rmcp_payload(n_bd_type, payload)` 分派器

```
atom/protocol/rmcp/parser.py
    parse_rmcp_payload(n_bd_type, payload) → band_info
        parse_fscan_payload(n_bd_type=15) → band_info
        parse_sglfreq_payload(n_bd_type=0x0E) → band_info
        parse_pscan_payload(n_bd_type=0x10) → band_info
        parse_ifanalysis_payload(n_bd_type=0x0B) → band_info
```

## P1 - PScan 端到端

**关键发现**:
- B_PScan 的 RMCP 回调是 n_bd_type=0x10 (DSCAN)
- 帧结构: `[n_bd_type][2B][counters(8B)][int16[N]]`
- 数据点: 605 个 int16
- counters[0] = 1441 (总通道数，非帧内数据点数)

### 任务

1. **分析 PScan RMCP 回调原始帧** — 对比 rmcp_proxy 捕获的 RMCP 帧 vs PScan streamsrc 帧
2. **分析 PScan streamsrc 帧格式** — `stream_B_PScan_18013_220836_270530.bin` (59205B)
3. **实现 push loop `mode='pscan'` 分支** — `server.py` 缺少该分支
4. **端到端测试** — SOAP B_PScan → RMCP → streamsrc 推送

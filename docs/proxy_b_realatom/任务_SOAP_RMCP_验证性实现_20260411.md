## 三、实现方案

### 3.1 SOAP → RMCP 转换模块

**文件**: `soap_proxy/soap_to_rmcp_converter.py`

**类**: `SOAPToRMCPConverter`

**功能**:
1. 接收SOAP XML
2. 解析参数
3. 构建RMCP帧 (含占位符)
4. 保存到本地

**RMCP帧结构**:
```
Bytes 0-3:   dwLength (4 bytes)
Bytes 4-7:   序列号占位符 (0x41)
Bytes 8-11:  魔数 (E6C9DC01)
Byte 12:     0x00
Byte 13:     nVersion (=7)
Byte 14:     nMsgType (=90)
Byte 15:     nFlags (=1)
Bytes 16-17: nCheckSum (占位)
Byte 18:     0x00
Byte 19+:    SOAP XML (GB2312)
```

### 3.2 rmcp_proxy DATA帧解析

**文件**: `rmcp_proxy/rmcp_proxy.py`

**方法**: `parse_fscan_data_simple()`

**DATA帧结构**:
```
偏移 0-17:   RMCP帧头 (18 bytes)
偏移 18-20:  业务头 (3 bytes, nBdType=0x0F)
偏移 21-28:  计数器 (8 bytes = 4 int16, 值为512,0,0,0)
偏移 29+:    频谱数据 (int16 little-endian)
```

**转换公式**: `dBm = raw_value / 10`

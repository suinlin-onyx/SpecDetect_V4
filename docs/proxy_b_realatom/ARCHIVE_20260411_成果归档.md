## 二、Python模块

**文件**: `SpecDetect_POC/soap_proxy/soap_rmcp_converter.py`

### 已完成函数

```python
# SOAP XML解析
parse_soap_request(xml_content) -> Dict
    - 提取funcid, stationid, deviceid, startfreq, stopfreq, step等
    - 频率字符串解析 (137MHz -> 137000000)

# RMCP REQUEST帧解析
parse_rmcp_request_frame(hex_str) -> Dict
    - 解析帧头 (dwLength, nMsgType, nFlags)
    - 提取嵌入式SOAP XML (从字节18开始，GB2312编码)

# RMCP DATA帧解析
parse_rmcp_data_frame(hex_str, startfreq, step) -> Dict
    - 提取频谱数据 (512/417点)
    - 转换: raw_int16 / 10 = dBm
    - 计算频率: startfreq + offset * step
```

### 验证命令

```bash
cd SpecDetect_POC/soap_proxy
python3 soap_rmcp_converter.py
```

## 三、关键发现

### 1. RMCP帧头结构 (18字节)

| 字节 | 内容 | 说明 |
|------|------|------|
| 0-3 | dwLength | 帧总长度 |
| 4-7 | 序列号? | 每次通信变化，规律未知 |
| 8-11 | E6C9DC01 | 固定魔数 |
| 12 | 0x00 | - |
| 13 | nVersion | =7 |
| 14 | nMsgType | 90=REQUEST, 6=RESPONSE, 0=DATA |
| 15 | nFlags | =1 |
| 16-17 | nCheckSum | 校验和 |

### 2. DATA帧结构 (实测验证)

```
偏移 0-15:   RMCP帧头 (18字节)
偏移 16-20:  业务头 (5字节)
偏移 21-28:  计数器 (512, 0, 0, 0) - int16
偏移 29+:    频谱数据 - int16 little-endian
```

### 3. 转换公式

```
dBm = raw_int16_value / 10
```

**验证**:
- 误差: -0.2 ~ -0.9 dBm (TestTool取整)
- 样本: 1441个数据点全部验证通过

### 4. SOAP ↔ RMCP对应关系

| SOAP操作 | RMCP funcid | 状态 |
|----------|-------------|------|
| B_FScan | 15 | ✅ 已确认 |
| B_FScanDF | 21 | ✅ 已确认 |
| B_MScan | 14 | ✅ 已确认 |
| B_StopMeas | 32 | ✅ 已确认 |

**SOAP XML嵌入方式**:
- 位置: 从RMCP帧字节18开始
- 编码: GB2312

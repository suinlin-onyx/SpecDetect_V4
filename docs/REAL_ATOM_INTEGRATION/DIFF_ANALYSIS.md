## Real Atom 特有行为

### streamsrc vs RMCPTP 双通道架构 (2026-04-11 更新)

Real Atom 与设备之间有**两个独立的通信通道**：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        streamsrc vs RMCPTP 双通道                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  streamsrc通道 (长连接):                                                   │
│  ┌─────────┐                              ┌─────────┐                      │
│  │  设备   │◀─────────────────────────────│ Real    │                      │
│  │ :9997   │     设备主动连接              │ Atom    │                      │
│  └─────────┘     数据回调                  │ :18012  │                      │
│              (心跳保活)                      └─────────┘                      │
│                                                                             │
│  RMCPTP通道 (短连接):                                                     │
│  ┌─────────┐                              ┌─────────┐                      │
│  │ Real    │─────────────────────────────▶│  设备   │                      │
│  │ Atom    │     Atom主动连接              │ :9997   │                      │
│  │ :8282   │     SOAP业务命令/响应         └─────────┘                      │
│  └─────────┘                                                              │
│                                                                             │
│  注意: 两个通道完全独立, 设备需同时维护 streamsrc 长连接才能正常通信         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 通道 | 方向 | 角色 | 连接模式 | 用途 |
|------|------|------|----------|------|
| **streamsrc** | 设备→Atom | Atom是TCP服务端，设备是客户端 | **长连接** | 设备数据回调、心跳保活 |
| **RMCPTP** | Atom→Device | Atom是TCP客户端，设备是服务端 | **短连接** | SOAP业务命令/响应 |

**通信流程**:
```
1. 设备启动后主动连接 Atom 的 streamsrc 端口 (长连接)
2. m_bIsConnected = 1
3. SOAP请求到达 Real Atom (8282)
4. Real Atom 通过 streamsrc 长连接发送 RMCPTP 命令到设备
5. 设备处理并通过同一 streamsrc 连接返回数据
6. Real Atom 返回 SOAP 响应
```

**streamsrc 配置** (`atomsvcconfig.xml`):
```xml
<streamsrc ip="127.0.0.1" port="18012" />
```
- `ip`: Atom 监听的网络接口，设备需连接此地址
- `port`: 监听端口，缺省值为 18012

**注意**: RMCPTP 通道(devinfo配置的serverport)和 streamsrc 通道是**完全独立的**，设备需要同时维护 streamsrc 长连接才能正常通信。

```
│  └─────────────────────┘    └─────────────────────┘                     │

```

> **通信连接模式说明**
>
> 原始 RMCPTP v2.0 协议规定的通信模式为**短连接**：
> - "每执行一功能，均单独建立一连接"
> - "客户端发起连接 → 发送请求命令 → 服务端应答 → 业务处理 → 双方断开连接"
>
> 本 HLD 中描述的心跳保活、重连机制、长连接池等是 **设计选择**，用于需要保持连接活跃的场景。
>
> 按原始协议实现时，可采用短连接模式，无需心跳机制。

### 2.2 分层职责说明

| 层次 | 名称 | 主要职责 | 技术要点 |
|------|------|----------|----------|
| L1 | Web应用层 | 用户交互、界面展示 | HTML5/CSS3/JavaScript |
| L2 | 代理服务层 | SOAP处理、认证授权、负载均衡、路由分发 | .NET Core/Java |
| L3 | 原子服务层 | 设备通信、协议解析、业务处理、服务模拟 | C++/C# |
| L4 | 设备层 | 真实设备控制、数据采集 | 厂商SDK/硬件接口 |

```xml

  <soap:Header>
    <mon:AuthToken>xxx-xxx-xxx</mon:AuthToken>
  </soap:Header>
  <soap:Body>
    <mon:StartMeasureRequest>
      <mon:TaskID>task-001</mon:TaskID>
```

# 任务：Mock Atom 完整实现

> 创建日期：2026-04-10

---

## 任务目标

使用 Mock Atom 替换 Real Atom，跑通完整流程：
```
请求侧 → SOAP → Mock Atom → rmcp_proxy → 远程Device
```

---

## 当前架构

| 组件 | 说明 |
|------|------|
| Real Atom | 已完成联调，支持所有 SOAP 接口 |
| Mock Atom | 待完整实现，缺少 RMCPTP 转发 |
| rmcp_proxy | TCP 透明代理，监听 9996 |

### 2. Mock Atom RMCPTP 转发

**问题**：Mock Atom 需要将 SOAP 请求转换为 RMCPTP 帧并转发

**需要实现**：
1. SOAP 请求解析
2. RMCPTP 帧构建（参考 Real Atom 捕获的数据）
3. TCP 转发到 rmcp_proxy (9996)
4. 接收 RMCPTP 响应并转换回 SOAP 响应

### 3. streamsrc 监听功能

**问题**：Real Atom streamsrc (18012) 监听端口，设备主动连接

**需要实现**：
1. Mock Atom 添加 streamsrc 监听模块
2. 接收设备连接
3. 维护连接并接收设备数据

## 任务顺序

### 阶段1：Mock Atom SOAP 接口实现

1. 创建 `mock_atom_interfaces.py` - 实现所有 SOAP 接口
2. 复用 Real Atom 接口定义（参考 `test_interface_sequence.py`）
3. 测试单接口响应

### 阶段2：Mock Atom RMCPTP 转发

1. 实现 `RMCPTPFrameBuilder` - 构建 RMCPTP 请求帧
2. 实现 `RMCPTPResponseParser` - 解析 RMCPTP 响应帧
3. 实现 TCP 客户端，连接 rmcp_proxy (9996)
4. 集成转发逻辑到接口处理

### 阶段3：streamsrc 监听（可选）

1. 添加 asyncio TCPServer 监听 18012
2. 接收设备连接
3. 维护设备连接状态

### 阶段4：端到端测试

1. 启动 Mock Atom
2. 启动 rmcp_proxy
3. 发送测试请求
4. 验证完整流程

## 2. 系统概述

### 2.1 系统目标

超短波监测管理一体化服务系统旨在统一管理来自不同厂家、遵循无线电协议2.0的无线电监测设备。通过原子服务层的抽象，实现向上层应用提供统一的SOAP协议接口，解决设备种类多、技术标准不一、操作方式差异等带来的集成困难问题。

### 2.2 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      Web应用层                               │
│                   (客户端/浏览器)                             │
└─────────────────────┬─────────────────────────────────────┘
                      │ HTTP/SOAP
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    代理服务层 (Proxy Service)                  │
│                  SOAP 1.1/1.2 协议处理                        │
└─────────────────────┬─────────────────────────────────────┘
                      │ SOAP/XML
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    原子服务层 (Atom Service)                   │
│  ┌─────────────────┐         ┌─────────────────┐           │
│  │  AtomSvcV3      │         │  Mock Service   │           │
│  │  (真实服务)      │         │  (模拟服务)      │           │
│  └─────────────────┘         └─────────────────┘           │
└─────────────────────┬─────────────────────────────────────┘
                      │ 无线电协议2.0 (RX-RMCPTP)
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                    设备层 (Device Layer)                     │
│  ┌─────────────────┐         ┌─────────────────┐           │
│  │   真实设备       │         │   模拟设备       │           │
│  │ (Real Device)   │         │(Simulated Device)│          │
│  └─────────────────┘         └─────────────────┘           │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 技术选型

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| Web接口 | SOAP 1.1/1.2 | 基于GWJ002-2015规范 |
| 代理服务 | .NET Core/Java | 跨平台服务 |
| 原子服务 | C++/C# | 设备通信核心 |
| 设备协议 | TCP/IP + 自定义二进制 | RX-RMCPTP v2.0 |

### 3.2 功能需求详细说明

#### 3.2.1 单频测量服务 (SglFreqMeasure)

**功能描述：** 对指定频率进行实时监测，获取信号强度、频偏、调制参数等ITU标准测量数据。

**输入参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Frequency | Int64 | 是 | 监测频率，单位Hz |
| Antenna | String | 是 | 天线名称 |
| IFBW | Int64 | 否 | 中频带宽，单位Hz |
| Span | Int64 | 否 | 测量跨距，单位Hz |

**输出参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| ITUResults | Array | ITU测量结果数组 |
| Frequency | Int64 | 实际工作频率 |
| Level | Float | 信号电平 |
| Occupancy | Short | 占用度（值*100） |

**业务数据格式：**

```
数据类型: 0x10 (SGLFREQ)
静态部分: [nBdType(1B), nArrays(4B), freq(8B), szAntenna[64](64B)]
动态部分: [szITUName[16](16B), fMinValue(4B), szUnit[10](10B)]
```

#### 3.2.2 扫频频谱观测服务 (FScan)

**功能描述：** 对指定频段进行扫描，获取频谱占用情况和信号分布。

**输入参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| StartFreq | Int64 | 是 | 开始频率，单位Hz |
| EndFreq | Int64 | 是 | 结束频率，单位Hz |
| Step | Int64 | 是 | 步长频率，单位Hz |
| Points | Int32 | 是 | 本段点数 |

**输出参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| ScanResults | Array | 扫描结果数组 |
| Occupancy | Int64 | 占用度（高4B有效采样/低4B总采样） |
| NoiseFloor | Short | 噪声底 |

**业务数据格式：**

```
数据类型: 0x15 (FSCAN)
静态部分: [nBdType(1B), nArrays(4B)]
动态部分: [startfreq(8B), endfreq(8B), Step(8B), nPoints(4B)]
```

#### 3.2.3 中频测向服务 (IFDF)

**功能描述：** 对中频信号进行测向，测定信号来波方向。

**输入参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Frequency | Int64 | 是 | 测量中心频率，单位Hz |
| Span | Int64 | 是 | 测量跨距，单位Hz |
| IFBW | Int64 | 是 | 中频带宽，单位Hz |

**输出参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Level | Short | 电平（实际值*100） |
| DfLevel | Short | 测向电平（实际值*100） |
| Quality | Float | 测向质量 |
| Azimuth | Float | 方位角 |
| Elevation | Float | 俯仰角 |
| Compass | Float | 罗盘值 |

#### 3.2.4 宽带FFT测向服务 (WBDF)

**功能描述：** 宽带频段内的测向功能，支持全景频段、局部频段和中频频谱三种模式。

**输入参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| HeadType | Byte | 是 | 描述头类型（0:全景 1:局部 2:中频） |
| StartFreq | Int64 | 否 | 开始频率（HeadType=0,1时） |
| EndFreq | Int64 | 否 | 结束频率（HeadType=0,1时） |
| Frequency | Int64 | 否 | 中心频率（HeadType=2时） |

**输出参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| DataType | Byte | 数据类型（0:全景 1:局部 2:频谱） |
| Points | Int32 | 总点数 |
| Compass | Short | 罗盘值（实际值*100） |
| Results | Array | 测向结果数组 |

#### 3.2.5 设备状态查询服务 (QueryFacilityDevStatus)

**功能描述：** 查询监测站设备和组合的工作状态。

**输入参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| StationID | String | 是 | 监测站编号（8字符） |
| EquipmentID | String | 是 | 设备组合标识（3字符） |
| SubEquipmentID | String | 否 | 相同设备组合序号（2字符） |

**输出参数：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Status | Int32 | 设备状态码 |
| OnlineTime | DateTime | 最近在线时间 |
| Capabilities | Array | 设备能力列表 |

### 3.3 数据传输需求

#### 3.3.1 请求/响应模式

- XML格式的SOAP请求/响应

#### 3.3.2 数据流推送模式

#### 3.3.3 数据获取方式

| 方式 | 说明 |

| 直接返回 | 响应中直接携带数据 |
| 数据库 | 数据存储至指定数据库 |
| FTP | 数据推送至FTP服务器 |
| URL | 数据推送至指定HTTP URL |

```xml

  </detail>

```

### 5.3 协议帧格式

#### 5.3.1 RX-RMCPTP帧头结构

```c
#pragma pack(push,1)
typedef struct tagRmcpFrame {
    DWORD       dwLength;    // 报文长度(BYTE)
    FILETIME    tmStamp;     // 报文产生时间
    WORD        nVersion;    // 报文版本号 (当前: 0x0007)
    BYTE        nDataType;   // 报文数据类型
    BYTE        nFlags;      // 报文标志
    WORD        nCheckSum;   // 头校验和
} RMCPFRAME;
#pragma pack(pop)
```

| nDataType值 | 数据类型 | 说明 |
|-------------|----------|------|

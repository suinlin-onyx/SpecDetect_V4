## 1. 文档概述

### 1.1 目的

本文档定义频谱探测系统（SpecDetect_V1）的Python快速验证策略，用于在正式开发前验证核心业务流程的可行性。验证目标：Web → 代理服务 → 原子服务 → 虚拟设备的数据流转。

### 1.2 背景

- **现状**：现有开发文档基于C++/C#设计，但尚未实现
- **目标**：使用Python进行快速原型验证，降低开发风险
- **约束**：缺少真实监测设备，需使用虚拟设备模拟

### 1.3 验证范围

| 层级 | 验证内容 | 优先级 |
|------|----------|--------|
| Web客户端 | 请求发起与响应展示 | P0 |
| 代理服务 | SOAP协议解析与转发 | P1 |
| 原子服务 | 业务逻辑处理与命令封装 | P1 |
| 虚拟设备 | RMCPTP协议数据模拟 | P1 |
| 数据链路 | 全链路数据流转 | P0 |

## 6. RMCPTP协议实现要点

### 6.1 帧头结构（18字节）

```python
# 参考: 06_RMCPTP_v2.0_无线电协议规范.md

RMCPTP_FRAME_HEADER = {
    'dwLength': 'I',      # 4字节: 报文长度
    'tmStamp': 'Q',       # 8字节: 报文时间戳
    'nVersion': 'H',      # 2字节: 版本号 (0x0007)
    'nDataType': 'B',     # 1字节: 数据类型
    'nFlags': 'B',        # 1字节: 标志位
    'nCheckSum': 'H',     # 2字节: 校验和
}
# 总计: 18字节
```

### 6.2 报文数据类型

| 值 | 类型 | 说明 |
|----|------|------|
| 0x00 | 监测业务数据 | 业务数据 |
| 0x01 | 音频描述头 | 音频数据描述 |
| 0x02 | 音频数据 | 音频流 |
| 0x03 | 分发请求 | 数据分发请求 |
| 0x04 | 信息数据 | 文本信息 |
| 0x06 | 业务数据描述头 | 自描述头 |

### 6.3 业务数据类型

| 类型ID | 名称 | 说明 |
|--------|------|------|
| 0x10 | SGLFREQ | 单频测量 |
| 0x11 | FSCAN | 频段扫描 |
| 0x12 | WBFFT | 宽带FFT |
| 0x15 | IFDF | 中频测向 |
| 0x16 | SGLFREQDF | 单频测向 |

### 10.7 可视化实现方案（方案D）

#### 方案概述

采用**完整可视化控制台**方案，提供专业的数据验证界面，支持人工确认协议正确性和数据合理性。

#### 技术选型

| 组件 | 技术选型 | 理由 |
|------|----------|------|
| 前端框架 | 原生HTML + CSS + JavaScript | 零构建，快速部署 |
| 图表库 | ECharts | 丰富的频谱图支持 |
| 实时通信 | HTTP轮询 | 简化实现，满足需求 |
| 代码高亮 | highlight.js | SOAP/XML展示 |
| 无需构建工具 | 直接浏览器打开 | 快速迭代 |

#### 分阶段实现计划

| 阶段 | 组件 | 目标 | 优先级 | 工作量 |
|------|------|------|--------|--------|

| **Phase 2** | 测向指示、状态指示 | 辅助展示 | P1 | 1天 |

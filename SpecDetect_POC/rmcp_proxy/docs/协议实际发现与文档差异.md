# 协议实际发现与文档差异

本文档记录开发过程中发现的与原始协议文档(RMCP_Protocol_v2.0.md)的差异。

---

## 1. 数据帧的nMsgType值 - 重要差异

### 原始文档记载
```
数据帧: nMsgType = 0x1D (29) 或 0x5F (95)
```

### 实际观察到
```
数据帧: nMsgType = 0 (UNKNOWN(0))
```

### 日志证据
```
Time: 2026-04-10 18:42:32.761
Direction: S->C
Size: 1053 bytes
Frame Header:
  dwLength: 1053
  nVersion: 7
  nMsgType: 0 (UNKNOWN(0))  ← 文档说应该是29或95
  nFlags: 0x01
```

### 可能原因
1. 文档版本与实际设备固件不一致
2. 数据帧的nMsgType含义被重新定义
3. 不同功能使用不同的nMsgType编码规则

### 影响
- `RMCPFrame.get_msg_type_name()` 将返回 `UNKNOWN(0)` 而非预期的 `DATA_29` 或 `DATA_95`
- 帧解析器本身是正确的，只是消息类型名称映射表需要更新

## 2. 设备返回非RMCP数据 - 文档未记载

### 发现
设备在某些情况下会返回**非RMCP格式**的数据，长度通常为61字节：

### 数据格式
```
RMTP:ErrCode=-1,INFO=<GB2312编码的错误信息>
```

### 示例
```
十六进制: 524d54503a457272436f64653d2d312c494e464f3db4f2bfaac9e8b1b8b9a6c4dccaa7b0dc5bc9e8b1b849443a30303130365d5bb9a6c4dc3a32315d0a

解码后:
RMTP:ErrCode=-1,INFO=设备连接失败[设备ID:00106][功能:21]
```

### 字段说明
| 字段 | 说明 |
|------|------|
| RMTP | 协议标识 (Radio Monitoring Transfer Protocol) |
| ErrCode | 错误码，-1通常表示失败 |
| INFO | 错误详情，GB2312编码 |

### 影响
- 帧解析器会返回 `header = None`，数据被标记为 `RAW_DATA`
- 这是设备的主动通知，不是RMCP帧，不应被视为协议错误

## 3. 帧头验证规则 - 文档未定义

### 开发中添加的验证规则

#### nVersion验证
```python
if nVersion != 7:
    return None
```
**文档说明**: nVersion应为7 (大端序)
**实际处理**: 如果不是7则视为无效帧

#### dwLength验证
```python
if dwLength > 65535:
    return None
```
**原因**: 异常大的长度值表明不是有效的RMCP帧

#### tmStamp (FILETIME) 验证
```python
if tmStamp < 116444736000000000 or tmStamp > 140000000000000000:
    return None
```
**原因**: FILETIME从1601年开始，有效范围应在此期间

### 文档补充
原始文档只说明字段类型，未定义有效性验证规则。这些规则是开发过程中根据实际数据总结的。

## 7. nFlags标志位 - 文档描述与实际不完全匹配

### 文档记载
```
标志位定义 (nFlags):
  位 7-1: 预留
  位 0: 请求/响应标志? (0=响应, 1=请求?)
```

### 实际观察

| 帧类型 | nMsgType | nFlags | 文档描述 |
|--------|----------|--------|----------|
| 请求帧 | 90 | 0x01 | 1=请求 ✓ |
| 响应帧 | 6 | 0x00 | 0=响应 ✓ |
| 数据帧 | 0 | 0x01 | 1=请求? |

### 问题
数据帧的nFlags也是0x01，但数据帧不是请求。文档的"请求/响应标志"解释不适用于数据帧。

### 可能解释
1. nFlags的含义可能不是简单的请求/响应标志
2. bit 0可能表示"后续有数据载荷"(payload indicator)
3. 或者文档描述不准确

## 8. 文档中标记为"?"的未知项

### 消息类型表格中的未知项
文档中nMsgType或nDataType标记为"?"的有12个:

| nMsgType/nDataType | 文档标注 |
|-------------------|----------|
| 16 | 数字扫描 |
| 29 | 噪声测量 |
| 31 | 离散监测 |
| 36 | 干扰信号 |
| 37 | IQ占用度 |
| 38 | GPS占用度 |
| 39 | DDC占用度 |
| 42 | 音频 |
| 45 | 信号压扩 |
| 46 | 模拟检波 |
| 47 | 峰值检波 |
| 48 | 频谱图 |
| 49 | 偏置估算 |
| 50 | 频率偏移 |
| 51 | 业务 |

### 说明
这些是业务数据类型(nDataType)，位于帧载荷内部，需要解析实际业务数据才能验证。代理程序目前只解析帧头，不解析业务数据载荷。

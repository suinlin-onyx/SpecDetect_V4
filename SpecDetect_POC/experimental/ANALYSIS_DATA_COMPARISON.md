## 二、streamsrc 帧结构

**65 bytes = 130 hex chars**

| Offset | 字段 | 示例值 |
|--------|------|--------|
| 0-3 | 0xEEEEEEEE | eeeeeeee |
| 4-11 | FILETIME | 0100c647de69ea07 |
| 12-15 | 用途未知 | 040e1539 |
| 16-17 | 帧编号 | 1c2b |
| 18 | FSCAN类型低 | 00 |
| 19 | 序列号 | 26 |
| 20 | FSCAN类型高 | 04 (529) / 03 (434) |
| 21-27 | 用途未知 | 0000000c210400 |
| 28-63 | 电平数据 | 36 bytes (18 × 2) |

**关键发现:**
- 序列号 0x26 = 38 (FSCAN-529) / 0x68 = 104 (FSCAN-434)
- 序列号在同一扫描类型中保持不变
- 帧编号递增 (唯一标识每帧)

## 三、数据转换分析

### 3.1 streamsrc → dBm 转换 (文档公式)

```python
SS_MIN = -32768  # 无效值
SS_MAX = 24933   # 最大值
DBUV_MIN = 0.0
DBUV_MAX = 78.9

def streamsrc_to_dbm(val):
    if val == SS_MIN:
        return None
    norm = (val - SS_MIN) / (SS_MAX - SS_MIN)
    dbuv = DBUV_MIN + norm * (DBUV_MAX - DBUV_MIN)
    dbm = dbuv - 107.6
    return round(dbm, 1)
```

**转换示例:**

| streamsrc | dBm |
|-----------|-----|
| 24933 | -28.7 |
| 21736 | -33.1 |
| 20480 | -34.8 |
| 18115 | -38.0 |
| 16801 | -39.8 |
| 12288 | -46.0 |
| 0 | -62.8 |
| -9531 | -75.8 |

### 3.2 rmcp 数据范围

- **范围**: [-101.9, -26.0] dBm
- **单位**: dBm (实际值, 不需要转换)
- **存储**: 实际值 × 100 (如 -55.0 存储为 -5500)

## 五、假设与推测

### 假设1: streamsrc 对 rmcp 数据做了归一化处理

**依据**: streamsrc 值范围集中在 [0, 24933]，而 rmcp 是真实 dBm 值

**可能处理**:
- 将 rmcp 的 dBm 值归一化到 [0, 1]
- 再映射到 streamsrc 的 [0, 24933] 范围

### 假设2: streamsrc 只传输有效信号

**依据**: streamsrc dBm 范围 [-75.8, -28.7] 比 rmcp [-101.9, -26.0] 窄

**可能处理**:
- 过滤低于噪声门限的信号
- 低于 -75 dBm 的值映射为 -32768 (无效)

### 假设3: streamsrc 和 rmcp 是不同层面的数据

**依据**: streamsrc 13点/帧 vs rmcp 512点/块

**可能关系**:
- rmcp = 完整频谱数据
- streamsrc = 实时监测/告警数据 (子集)

## 六、关键发现

### 6.1 streamsrc 帧交替模式

**发现**: FSCAN-529 帧在两种数据模式间交替:
- Pattern A: 首值 > 0 (如 21736)
- Pattern B: 首值 < 0 (如 -9336)

**72 帧 Pattern A, 72 帧 Pattern B**, 共 144 帧

### 6.2 metadata 完全相同

**所有 144 个 FSCAN-529 帧的 metadata 都是 [256, 1441, 0, 0, -32768]**

这表明 metadata 不是帧序列指示器，而是扫描配置参数。

### 6.3 dBm 值分布

| dBm 值 | 出现次数 | 可能含义 |
|--------|----------|----------|
| -63 | 648 | **噪声门限/默认值** |
| -40 | 288 | 信号峰值 |
| -62 | 216 | 近噪声门限 |
| -46 | 144 | 信号 |
| -76 | 144 | 弱信号 |

**关键洞察**: -63 dBm 出现最频繁，可能是 streamsrc 的底噪门限值。

### 6.4 streamsrc 与 rmcp 值范围对比

| 属性 | streamsrc | rmcp |
|------|-----------|------|
| dBm 范围 | [-75.8, -28.7] | [-101.9, -26.0] |
| 常见值 | -63 dBm | 变化较大 |
| 最低值 | -75.8 dBm | -101.9 dBm |

**假设**: streamsrc 过滤掉了低于 -76 dBm 的信号，只传输高于噪声门限的数据。

## 七、假设与推测

### 假设1: streamsrc 是实时功率监测，非完整频谱

**依据**:
- streamsrc 529 点 vs rmcp 512 点 (点数不同)
- streamsrc 值范围较窄 [-75.8, -28.7] vs rmcp [-101.9, -26.0]
- metadata 固定不变，不是帧序列

**可能**: streamsrc 用于实时监测/告警，只传输有效信号

### 假设2: Pattern A/B 交替表示双通道数据

**依据**: 帧交替显示不同的首值符号

**可能**: 双天线输入或 I/Q 通道分离

### 假设3: streamsrc 原始值 0 = 噪声门限以下

**依据**: -63 dBm 出现最频繁，而 0 转换为 -62.8 dBm

**可能**: streamsrc 中 0 表示低于设定阈值，不是真实测量值

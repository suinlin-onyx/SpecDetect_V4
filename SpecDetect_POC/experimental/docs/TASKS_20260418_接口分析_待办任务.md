```

4       2     VER         1 或 16        ✅ pcap确认

10      8     TS          FILETIME       ✅ pcap确认
18      2     PL          payload长度    ✅ pcap确认 (大端)

## 四、接口识别逻辑

### 根据 resulttype 识别

```python
def identify_interface_type(resulttype_xml):
    """根据 resulttype XML 识别接口类型"""
    if "<MSCAN" in resulttype_xml:
        return "MSCAN"      # B_MScan
    elif "<PSCAN" in resulttype_xml:
        return "PSCAN"      # B_SglFreqMeas
    elif "ITU" in resulttype_xml or "audio" in resulttype_xml:
        return "ITU_AUDIO"  # B_PScan
    else:
        return "UNKNOWN"
```

### Task #15: 实现 MSCAN 单点测量模式 (B_MScan)
**接口**: B_MScan
**依赖**: 无
**难度**: ⭐⭐ 简单
**问题**: 当前只支持 PSCAN，不支持 MSCAN

**帧格式 (pcap 确认)**:
- VER: 1 (小端)
- DT: 13
- PL: 21 (大端)
- 总长度: 45字节
- 帧头: 24字节
- Payload: 21字节

**频率值来源**: 从 SOAP 请求参数获取，test tool 会在显示时使用

**pcap 帧数据示例**:
```
eeeeeeee 0100 0383e369 ea070412150b23f3 0015 0000  | 0d 10 00000001 00010000...0084d797412c00
```
LEADER   VER  STC         TS                    PL EL | DT DL freq_count ...
```

**Payload 结构 (21字节)**:
| Offset | 大小 | 字段 | 说明 |
|--------|------|------|------|
| 0 | 1 | DT | 0x0d = 13 |
| 1 | 1 | DL | 0x10 = 16 |
| 2 | 4 | freq_count | 1 |
| 6 | 13 | 频率值/其他 | 待分析 |
| 19 | 2 | 电平值 | offset 43-44, LE ✅ |

**pcap 验证**:
- Frame offset 43-44 = level (小端序, 2字节) ✅
- 示例: 0x32 0x00 → LE = 0x0032 = 50
- ⚠️ 频率值不在帧数据中，test tool 从请求参数显示

**帧数据来源假设**:
- device 只发送电平数据
- 频率值由 test tool 根据请求参数 (frequency=100000000) 直接显示
- 帧中 offset 30-37 是固定值 (0001000000000000)，可能不是频率

**MSCAN 帧数据结构**:
| offset | 大小 | 字段 | 说明 |
|--------|------|------|------|
| 0 | 1 | DT | 0x0d |
| 1 | 1 | DL | 0x10 |
| 2 | 4 | freq_count | 1 |
| 6 | 8 | 固定值 | 0x0001000000000000 |
| 14 | 4 | ? | 未知 |
| 19 | 2 | level | offset 43-44, LE ✅ |

**实现方案**:
```python
def build_mscan_frame(stc, filetime, frequency_hz, dbm_level):
    """构建 MSCAN 频率表扫描帧 (45字节)"""
    frame = bytearray(45)

    # 帧头 24字节
    frame[0:4] = struct.pack('>I', 0xEEEEEEEE)  # LEADER (大端)
    frame[4:6] = struct.pack('<H', 1)           # VER (小端)
    frame[6:10] = struct.pack('<I', stc)        # STC (小端)
    frame[10:18] = struct.pack('>Q', filetime)  # TS (大端)
    frame[18:20] = struct.pack('>H', 21)       # PL (大端) = 21
    frame[20:22] = struct.pack('>H', 0)         # EL (大端)

    # Payload (21字节)
    frame[24] = 13   # DT
    frame[25] = 16   # DL
    frame[26:30] = struct.pack('>I', 1)        # freq_count = 1
    # offset 30-37: 固定值 0x0001000000000000
    frame[30:38] = bytes([0x00, 0x01, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00])

    # 电平值在 offset 43-44 (小端序)
    struct.pack_into('<H', frame, 43, dbm_level)

    return bytes(frame)
```

**验证**: 回显显示 100MHz, 电平随时间变化 (33-56)

# GWJ006 帧数据结构 ↔ Device 数据映射

**日期**: 2026-04-15
**来源**: GWJ006-2016《超短波频段监测基础数据存储结构技术规范》PDF §5.2
**说明**: GWJ006 规定**磁盘文件格式**（非网络协议），记录 device→文件的存档结构。

---

## 通用字段（所有文件类型共享）

| 字段 | device 数据来源 | 说明 |
|---|---|---|
| 月/日/时/分/秒/纳秒 | device 本地时钟 | 每帧独立时间戳 |
| 经度/纬度/天线挂高 | device GPS + 配置 | 移动模式必填；固定模式可复用前序帧 |
| STC (同步传输编码) | device 通道分配 | 唯一标识一路采集通路 |
| 电平无效值 `0xEFFF` | device 检测异常 | 标识该频点测量无效 |

## 各业务类型映射

### 1. spectrum / FSCAN (§5.2.1, §5.2.2) —— 宽带频谱扫描

```
扫描段0 | 扫描段1 | ... | 扫描段m   ← device 一个扫频周期的分片
  ├─ 频率点总数量 (INT32)           ← 扫频配置: (终止-起始)/步长
  ├─ 起始频率 (FLOAT64 Hz)          ← 当前扫描段起始频率
  ├─ 频率点序号 (INT32)             ← 分片在整周期中的偏移 ★重组关键
  ├─ 频率点数量 (INT32)             ← 本分片电平个数
  └─ 电平[] (INT16 × 0.1 dBμV)      ← device FFT 结果 × 10
```
→ device 的一次扫频被切成 m 个扫描段，靠 **频率点序号** 重组

### 2. PSCAN —— 频点扫描

```
频点数量 | (频率, 电平) 列表
```
→ 离散频点监测，device 直接给 (f, level) 对

### 3. MSCAN (§5.2.3) —— 频率表扫描
同 spectrum 结构，仅扫描预配置频率表。

### 4. SFDF (单频测向, §5.2.10)

```
示向度数量 | 数据点[]
  ├─ 示向度 (INT16, 0.1°)         ← device 相关干涉仪/比幅算法输出
  ├─ 电平 (INT16, 0.1 dBμV)       ← device 接收机电平
  ├─ 测向质量 (UINT8, 1~99)       ← device 置信度
  └─ 俯仰角 (可选)
```

### 5. WBDF (宽带测向, §5.2.11)
类似 FSCAN，每点同时带 (示向度, 电平, 测向质量)。

### 6. MSCANDF (频率表测向, §5.2.12)
类似 MSCAN，每点同时带测向三元组。

## 文件头字段（所有类型）

| 字段 | device 配置项 |
|---|---|
| 起始/终止频率 | 扫频范围 |
| 频率步长 | 分辨率 |
| 极化方式 (H/V/C) | 天线控制 |
| 测向体制 | 0-相关干涉仪 / 1-比幅 / 2-空间谱 / 3-其他 |
| 持续时间 | 测量秒数 |

## 核心映射原则

1. **电平**统一 `INT16 × 0.1 dBμV`（定点化），device 浮点 → ×10 整数
2. **分片重组**靠 `频率点序号`（偏移），不是时间顺序
3. **固定/扫频/测向**各自结构不同，但共享「时间+位置+电平」三元组
4. **`0xEFFF`** 是 device 测量失败占位
   - 与 Atom streamsrc 观察到的 `-32768` 不同，后者是私有协议的无效标记

## 与实际数据的对照

| 层级 | 协议/格式 | 无效值 | 分片机制 |
|---|---|---|---|
| device → Atom | RMCPTP | ? | nOffset |
| Atom → rmcp 客户端 | RMCPTP (记录为 raw_fscan_*.log) | 近似 GWJ006 | 频率点序号 |
| Atom → streamsrc (18012) | 私有协议 | `-32768` | offset 19 |
| 文件存档 | GWJ006 | `0xEFFF` | 频率点序号 |

**rmcp 流接近 GWJ006 格式**（frame 内含扫描段分片）；**streamsrc 是 Atom 私有压缩流**。

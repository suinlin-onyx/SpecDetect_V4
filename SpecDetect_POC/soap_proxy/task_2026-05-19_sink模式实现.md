# Task: Sink 模式 Stream 连接实现

## 任务日期

2026-05-19

## 任务背景

当前 Proxy 只实现了 source 模式的 stream 透明代理，需要新增 sink 模式支持。

## Source vs Sink 模式区别

| 特性                | source              | sink                        |
| ----------------- | ------------------- | --------------------------- |
| outputchannel 指定方 | 设备在回调中指定            | 请求侧在请求中指定                   |
| host:port 来源      | 设备指定 host=127.0.0.1 | 请求侧指定外部 host:port           |
| Atom 角色           | **服务端**，等待 Proxy 连接 | **客户端**，主动连接 Proxy          |
| Proxy → 目标        | 连接 Atom/设备 18012    | 连接 outputchannel 指定的外部地址    |
| 处理时机              | 响应回调时               | 请求时                         |
| 典型场景              | 设备推送数据到本地           | Atom 推送数据到外部地址如 172.18.98.5 |

## Sink 模式架构

```
Atom（客户端） ────────────── TCP 连接(1) ──────────────→ Proxy（服务器:port+1）
                                                                  │
                                                                  │ TCP 连接(2)
                                                                  ↓
                                                        原始 outputchannel 的 host:port
                                                        （如 172.18.98.5:8332）
```

## 流程说明

1. 请求侧发起 B_FScan 请求，outputchannel{mode=sink, host=172.18.98.5, port=8332}
2. Proxy 解析请求，确认 mode=sink
3. Proxy 修改 outputchannel：host=127.0.0.1, port=8333（port+1）
4. Proxy 转发修改后的请求给 Atom
5. Proxy 监听 127.0.0.1:8333
6. Atom 收到请求，作为客户端主动连接到 Proxy 的 127.0.0.1:8333
7. Proxy 收到 Atom 连接后，作为客户端连接到 172.18.98.5:8332
8. Proxy 双向透传 Atom ↔ 172.18.98.5:8332

## 实现要点

### 1. 请求解析与修改

- 在 `handle_http_client` 收到请求时，解析 outputchannel
- 判断 mode 是否为 sink
- 提取原始 host 和 port 保存
- 修改请求中 outputchannel：host=127.0.0.1, port=port+1

### 2. 代理启动函数

```python
def start_sink_proxy(listen_host, listen_port, target_host, target_port, interface_name):
    """启动 sink 模式透明代理"""
    # 1. Proxy 绑定并监听 listen_port (port+1)
    server_socket.bind((listen_host, listen_port))

    while True:
        # 2. 等待 Atom 连接 Proxy 的 listen_port
        atom_socket, atom_addr = server_socket.accept()

        # 3. Atom 连接成功后，才能连接外部目标
        target_socket = socket.create_connection((target_host, target_port))

        # 4. 双向透传
        forward(atom_socket, target_socket, "Atom->Host")
        forward(target_socket, atom_socket, "Host->Atom")
```

### 3. 核心坑点

| 坑点      | 说明                     | 处理方式            |
| ------- | ---------------------- | --------------- |
| 处理时机不同  | sink 在请求时，source 在响应时  | 区分处理            |
| 请求修改    | 需要提取原始 host:port 供后续连接 | 保存到会话结构         |
| 启动顺序    | 必须先监听，等 Atom 连接后再连外部目标 | 在 accept 后连接    |
| 端口冲突    | port+1 可能被占用           | 检查端口可用性         |
| 外部目标不可达 | 172.18.98.5:8332 可能不存在 | 超时处理、重试         |
| 会话管理    | 多并发需要独立会话              | SinkSession 类管理 |

### 4. 建议数据结构

```python
class SinkSession:
    """Sink 模式会话"""
    listen_port: int           # Proxy 监听的 port+1
    target_host: str           # 原始 outputchannel 的 host
    target_port: int          # 原始 outputchannel 的 port
    atom_socket: Optional[socket.socket] = None
    target_socket: Optional[socket.socket] = None
    interface_name: str        # B_FScan 等
    stc: str                  # stream 唯一标识
```

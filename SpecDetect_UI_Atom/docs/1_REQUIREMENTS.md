# SpecDetect_UI_Atom 需求概述

**创建日期**: 2026-04-16
**版本**: 1.1
**更新日期**: 2026-04-18

---

## 1.1 背景与目标

### 1.1.1 项目背景

现有 **荣新原子服务3.0测试工具** 用于测试Atom服务能力，功能完整但封闭。

### 1.1.2 项目目标

| 子项                | 目标                            |
| ----------------- | ----------------------------- |
| SpecDetect_Atom   | 复现Atom能力，与Atom相同的数据收发、处理、回调功能 |
| SpecDetect_Client | Web UI客户端（预留，当前未实现）           |

### 1.1.3 SpecDetect_Atom 目标

1. **复现Atom能力** - 实现与Atom相同的数据收发、处理、回调功能
2. **兼容测试工具** - 复现的服务能与现有测试工具对接匹配

---

## 1.2 功能需求

### 1.2.1 SpecDetect_Atom 接口列表

| 接口名                    | 功能       | streaming   | SOAP端口 | 状态    |
| ---------------------- | -------- | ----------- | ------ | ----- |
| B_QueryDeviceInfo      | 设备信息查询   | 否           | 8282   | ✅ 已实现 |
| B_QueryFacilityDevStat | 站点设备状态查询 | 否           | 8282   | 预留    |
| B_FScan                | 频谱扫描     | 是 (18012)   | 8282   | ✅ 已实现 |
| B_PScan                | 频段扫描     | 是 (FSCAN格式) | 8282   | ✅ 已实现 |
| B_MScan                | 多信道扫描    | 是 (18012)   | 8282   | ✅ 已实现 |
| B_StopMeas             | 停止测量     | 否           | 8282   | ✅ 已实现 |

**备注**：根据 Real Atom 抓包分析，B_PScan 请求返回的是 FSCAN 格式 (DT=12)，与 B_FScan 相同。

### 1.2.2 接口参数说明

#### B_FScan / B_PScan 参数

| 参数名        | 类型     | 说明        | 示例值       |
| ---------- | ------ | --------- | --------- |
| startfreq  | double | 起始频率 (Hz) | 137000000 |
| stopfreq   | double | 结束频率 (Hz) | 173000000 |
| step       | double | 频率步进 (Hz) | 25000     |
| gain       | string | 增益模式      | AGC       |
| rfworkmode | int    | 射频工作模式    | 0         |
| keepmode   | int    | 保持模式      | 0         |

#### B_MScan 参数

| 参数名       | 类型     | 说明        | 示例值       |
| --------- | ------ | --------- | --------- |
| frequency | double | 测量频率 (Hz) | 100000000 |
| ifbw      | string | 中频带宽      | (可选)      |

### 1.2.3 数据回调格式

| 接口      | 数据格式      | 帧大小       | 说明                    |
| ------- | --------- | --------- | --------------------- |
| B_FScan | streamsrc | 1086/896B | 三段式频谱数据               |
| B_PScan | streamsrc | 同 FSCAN   | Real Atom 返回 FSCAN 格式 |
| B_MScan | streamsrc | 45B       | 单频点电平数据               |

## 1.4 验证方法

### 1.4.1 复现验证

| 验证项         | 方法                 |
| ----------- | ------------------ |
| SOAP接口      | 使用测试工具调用，复现相同响应    |
| streamsrc回调 | 对比18012推送数据的完整性和时序 |
| 数据解析        | 对比频谱数据的解析结果        |

### 1.4.2 匹配测试

| 测试项  | 预期结果                |
| ---- | ------------------- |
| 站点配置 | 测试工具配置 = 复现系统配置     |
| 查询功能 | 双方返回相同接口列表          |
| 接口调用 | 双方调用相同接口，Device响应一致 |
| 数据回调 | 双方接收到的Streaming数据一致 |

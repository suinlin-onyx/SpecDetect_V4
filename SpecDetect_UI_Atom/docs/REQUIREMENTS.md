## 1. 背景与目标

### 1.1 背景

现有 **荣新原子服务3.0测试工具** 用于测试Atom服务能力，功能完整但封闭。

### 1.2 项目目标

1. **复现Atom能力** - 实现与Atom相同的数据收发、处理、回调功能
2. **兼容测试工具** - 复现的服务能与现有测试工具对接匹配

## 3. 功能需求

### 3.1 站点配置管理

| 功能 | 描述 | 输入 | 输出 |
|------|------|------|------|
| 站点保存 | 保存站点配置到本地 | 站点名称、服务器地址、MF ID、EQ ID | JSON配置文件 |
| 站点选择 | 下拉选择已保存的站点 | 站点列表 | 加载对应配置 |
| 配置验证 | 验证必填项 | MF ID、EQ ID | 有效/无效 |

**配置项说明**：

| 配置项 | 示例值 | 说明 |
|--------|--------|------|
| 站点名称 | "测试站点1" | 自由命名 |
| 服务器地址 | "127.0.0.1:8282" | Atom SOAP服务地址 |
| 设施ID / MF ID | "53090001140012" | 设备标识，用于Atom匹配预设 |
| 设备ID / EQ ID | "51cd8dfe-e543-40c9-bdc3-a292766fee7f" | 设备唯一标识 |

### 3.2 站点查询功能

| 功能 | 描述 | SOAP接口 | 状态 |
|------|------|----------|------|
| 测试功能查询 | 查询设备支持的功能列表 | B_QueryDeviceInfo | 已实现 |
| 监测功能查询 | 获取设备信息（接口列表） | B_QueryDeviceInfo | 已实现 |
| 动环功能查询 | (未实现，忽略) | - | 待定 |

**说明**：
- 监测功能查询实际上就是获取设备信息的接口（B_QueryDeviceInfo）
- 返回设备支持的接口列表：B_FScan、B_PScan、B_MScan等
- 每个接口的输入参数信息用于后续服务请求选择

### 3.3 服务请求功能

**前置条件**：先执行监测功能查询，获取可用接口列表

| 功能 | 描述 |
|------|------|
| 接口选择 | 从监测功能查询返回的接口列表中选择（如B_FScan） |
| 参数配置 | 设置接口调用参数（如频率范围137-173MHz、步进25kHz等） |
| 执行命令 | 通过RMCPTP协议发送到远程设备 |
| 响应接收 | 接收设备返回的响应数据 |

### 3.4 Streaming数据回调

| 功能 | 描述 |
|------|------|
| 自动建连 | 执行B_FScan等接口时，自动建立18012端口连接 |
| 数据推送 | Atom通过长连接推送实时数据 |
| 数据解析 | 解析streamsrc格式数据（1086字节帧） |
| 展示呈现 | 解析后展示频谱图/数据 |

**streamsrc数据格式**：

```
帧结构 (1086字节):
├── 0-23: GWJ004帧头 (24字节)
│   ├── 0-3: LEADER = 0xEEEEEEEE
│   ├── 4-5: VER = 1.00
│   ├── 6-9: STC (通道ID)
│   ├── 10-18: TS (时间戳)
│   ├── 19-22: PL = 1062
│   └── 23: EL = 0
├── 24-47: Atom私有元数据 (20字节)
└── 48+: 频谱数据 (512×int16)

解析算法:
vals = struct.unpack('<h' * ((len(data) - 48) // 2), data[48:])
spectrum = list(vals[7:7+512])  # 跳过7个元数据，取512点
```

## 4. 通信协议

### 4.1 协议链路

| 链路 | 协议 | 端口 | 说明 |
|------|------|------|------|
| Client → Atom | SOAP/HTTP POST | 8282 | 请求发送 |
| Atom → Client | WebSocket / TCP | 18012 | Streaming回调 |
| Atom → Device | RMCPTP/TCP | 1449 | 设备通信 |

### 4.2 RMCPTP协议结构

```
RMCPTP帧头 (18字节):
├── 1-4: dwLength (报文总长度)
├── 5-12: tmStamp (时间戳)
├── 13-14: nVersion (=7)
├── 15: nDataType
├── 16: nFlags
└── 17-18: nCheckSum

FSCAN业务数据:
├── nBdType = 15 (FSCAN)
├── nFlags
├── nArrays
└── nOffset (数组偏移)
```

### 4.3 SOAP接口列表

| 接口名 | 功能 | streaming |
|--------|------|-----------|
| B_QueryDeviceInfo | 设备信息查询 | 否 |
| B_QueryFacilityDevStat | 站点设备状态查询 | 否 |
| B_FScan | 频谱扫描 | **是 (18012)** |
| B_PScan | 频段扫描 | 是 |
| B_MScan | 多信道扫描 | 是 |
| B_StopMeas | 停止测量 | 否 |

```
Client                Atom                 Device
  │                    │                     │

  │                    │←────RMCPTP─────────│
```

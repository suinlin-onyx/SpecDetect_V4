## 2. PScan streamsrc 帧结构

### 2.1 帧组成

```
┌─────────────────────────────────────────────────────────┐
│                    1441 点                             │
├─────────────────────┬─────────────────────────────────┤
│   Payload (N点)     │         Gap (1441-N点)           │
│   spectrum数据       │   前(605-N)点: RMCP数据填充     │
│                     │   后836点: 高频填充 (-88 dBm)   │
└─────────────────────┴─────────────────────────────────┘
```

### 2.2 PL与Points关系

```
PL = 2 × points + 36
points = (PL - 36) / 2
```

| PL值 | Payload点数 | Gap点数 | FSCAN帧 |
|------|-----------|---------|---------|
| 104 | 34 | 1407 | #6,#9,#12 |
| 360 | 162 | 1279 | #3,#10 |
| 616 | 290 | 1151 | #1,#4,#7 |
| 872 | 418 | 1023 | #2,#5,#8,#11 |

## 4. streamsrc帧头结构 (62字节)

| Offset | 字段 | 大小 | 字节序 | 示例值 |
|--------|------|------|--------|-------|
| 0-3 | Sync | 4B | - | `EEEEEEEE` |
| 4-5 | VER | 2B | Little | `0100` = 1 |
| 6-9 | STC | 4B | Little | 通道标识 |
| 10-17 | Timestamp | 8B | - | FILETIME |
| 18-19 | Indicator | 2B | Big | `0268` |
| 20-23 | FSCAN Type | 4B | Little | `0B000000` |
| 24 | DT | 1B | - | `0C` = 12 (FSCAN) |
| 25 | DL | 1B | - | metadata+spectrum长度 |
| 26-61 | Metadata | 36B | - | 见下节 |
| 62+ | Spectrum | N×2B | Little | int16[] |

## 今日完成 (2026-04-20)

### Bug Fix: Band3 FSCAN Type 错误

**问题**: Band3 使用了错误的 FSCAN type (0x04000000)，应为 FSCAN-434 (0x03000000)

**影响**: test tool 接收 SpecDetect_Atom 发送的 Band3 帧时崩溃

**根因**: `fscan_processor.py` 中对所有频段使用固定的 `_FSCAN_TYPE = bytes([0x04, 0x00, 0x00, 0x00])`

**修复内容**:

| 文件 | 修改 |
|------|------|
| `src/atom/protocol/fscan_processor.py` | 新增 `_FSCAN_TYPE_434 = bytes([0x03, 0x00, 0x00, 0x00])` |
| `src/atom/protocol/fscan_processor.py` | 新增 `_get_fscan_type(start_index)` 函数 |
| `src/atom/protocol/fscan_processor.py` | 修改 `encode_for_streamsrc()` 使用 `_get_fscan_type(band)` |

**FSCAN Type 对照**:

| 频段 | start_index | FSCAN Type | 说明 |
|------|-------------|------------|------|
| Band1 | 0 | 0x04000000 | FSCAN-529 |
| Band2 | 512 | 0x04000000 | FSCAN-529 |
| Band3 | 1024 | 0x03000000 | FSCAN-434 |

**验证结果**:

```
Band1: frame_len=1086, DL=1057, FSCAN type=04000000 ✓
Band2: frame_len=1086, DL=1057, FSCAN type=04000000 ✓
Band3: frame_len=896,  DL=867,  FSCAN type=03000000 ✓
```

与 emulated_atom.py 帧格式完全一致，test tool 可正常接收。

## 帧格式参考

### streamsrc FSCAN 帧结构

```
Offset 0-3:   Sync (0xEEEEEEEE, little-endian)
Offset 4-5:   VER (0x0100, big-endian)
Offset 6-9:   STC (同步通道号, little-endian)
Offset 10-17: TS (8 bytes 时间戳)
Offset 18-19: Indicator (big-endian)
              - Band1: 0x0026
              - Band2: 0x0126
              - Band3: 0x0168
Offset 20-23: FSCAN Type
              - Band1/Band2: 0x04000000 (FSCAN-529)
              - Band3: 0x03000000 (FSCAN-434)
Offset 24:    DT (0x0C = FSCAN)
Offset 25-28: DL (little-endian, payload 长度)
Offset 29-61: Metadata (33 bytes)
Offset 62+:   Spectrum (交替字节模式 [dBm][0xFF]...)
```

### MSCAN 帧结构 (45B)

```
Offset 0-3:   Sync (0xEEEEEEEE, big-endian)
Offset 4-5:   VER (1, little-endian)
Offset 6-9:   STC (little-endian)
Offset 10-17: TS (8 bytes)
Offset 18-19: PL (21, big-endian)
Offset 20-21: EL (0, big-endian)
Offset 22-23: PAD (0)
Offset 24:    DT (13)
Offset 25:    DL (16)
Offset 26-29: freq_count (1, big-endian)
Offset 30-37: 固定值
Offset 38-41: 固定值
Offset 43-44: 电平值 (little-endian, 2字节)
```

### PScan 帧结构

| 帧类型 | DT | VER | 总长度 | PL | Payload |
|--------|----|-----|--------|-----|---------|
| 频谱 | 7 | 1 | 3256B | 3232 | 1601点×2 + 30 metadata |
| 电平 | 101 | 16 | 40B | 16 | 频率(8) + 电平(2) |
| ITU | 8 | 16 | 36B | 12 | ITU值(8) |

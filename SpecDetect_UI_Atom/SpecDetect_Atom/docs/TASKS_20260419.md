## B_FScan 调试问题分析 (2026-04-20)

### 现象
- 能收到数据，但 test tool 解析显示异常
- `步长:0.0000kHz` - 步长解析为0
- `帧信道数量:0` - 帧信道数量解析为0
- `PL:1062 DL:1057` - PL/DL数值正确

### 已修复
1. **Timestamp 编码格式** ✅ (2026-04-20)
   - 新增 `_get_streamsrc_timestamp()` 函数，与 emulated_atom.py 一致
   - 生成 8 字节时间戳 (year/month/day/hour/min/sec/ms)

2. **metadata start_index 设置** ✅ (2026-04-20)
   - 在 `encode_for_streamsrc()` 中动态设置 metadata[21] 位置的 start_index
   - 与 emulated_atom.py 一致

3. **STC 同步通道号** ✅ (2026-04-20)
   - 修改 `SpectrumData` 添加 `stc` 字段
   - 在 `_handle_fscan()` 中生成 `stc = int(time.time())`
   - 在 RMCP 接收线程中将 stc 传递到 band_info
   - 在 `encode_for_streamsrc()` 中使用 spectrum.stc

4. **FrameConstants/fscan.json 依赖问题** ✅ (2026-04-20)
   - 问题: `fscan.json` 被删除后，`FrameConstants` 返回全 0 metadata
   - 影响: test tool 显示"步长:0.0000kHz 帧信道数量:0"
   - 修复: 重构 `fscan_processor.py`，移除 `FrameConstants` 依赖
     - 硬编码 Band1/Band2/Band3 的 private_metadata (33 bytes) 直接在模块级别
     - 硬编码 Band indicator 值 (0x0026/0x0126/0x0168)
     - 使用模块级函数 `_get_band_metadata()` 和 `_get_band_indicator()`
   - `service.py` 更新: 移除 `FrameConstants` 导入和初始化

5. **VER 字节序错误** ✅ (2026-04-20)
   - 问题: `struct.pack('<IHI', sync, ver, stc)` 导致 VER 被写入为小端序 `00 01`
   - 影响: 日志中 VER 显示为 `0001` 而非 `0100`
   - 修复: 分离 VER 的打包，使用 `struct.pack('>H', ver)` 大端序
   - 修改: `frame = struct.pack('<I', sync) + struct.pack('>H', ver) + struct.pack('<I', stc)`

6. **数据平滑发送** ✅ (2026-04-20)
   - 问题: 设备数据快速到达，推送线程突发发送，导致客户端收到数据不平滑
   - 修复: 添加 `SmoothingBuffer` 类，按固定间隔（0.4秒）输出数据
   - `session.py`: 新增 `SmoothingBuffer` 类（deque + 时间间隔控制）
   - `streamsrc_server.py`: `_start_push()` 使用 `SmoothingBuffer`，替代直接推送
   - `BandCollector.get()`: 新增 `timeout` 参数支持

## RMCP → streamsrc 帧转换流程对比

### 数据流概述

```
设备(RMCP)                    SpecDetect_UI_Atom                  streamsrc客户端
   │                                │                                   │
   │  RMCP FSCAN Response           │  parse_fscan_payload()            │
   │  ────────────────────         │  ─────────────────────           │
   │  [18字节帧头]                   │                                   │
   │  [payload]                     │  counters[0]=n_arrays             │
   │    byte[0]: n_bd_type=15       │  counters[2]=start_index          │
   │    byte[3-10]: counters        │  levels[] = int16[]               │
   │    byte[11+]: levels (512点)   │                                   │
   │                                ↓                                   │
   │                                │  SpectrumData                     │
   │                                │    start_index = counters[2]      │
   │                                │    levels_raw = [int16, ...]     │
   │                                │    timestamp = 8字节              │
   │                                ↓                                   │
   │                                │  encode_for_streamsrc()           │
   │                                │  ─────────────────────           │
   │                                │  帧头(24B) + DT(1B) + DL(4B)     │
   │                                │  + metadata(33B) + spectrum       │
   │                                │                                   │
   │                                ↓                                   │
   ├────────────────────────────────▶  streamsrc Frame (1086B)         ──┤
                                     │  Sync(4) + VER(2) + STC(4)      │
                                     │  + TS(8) + Indicator(2)          │
                                     │  + FSCAN_type(4) + DT(1)        │
                                     │  + DL(4) + metadata(33)          │
                                     │  + [dBm][FF][dBm][FF]...        │
```

### 帧格式对比

| streamsrc偏移 | 字段 | emulated_atom | SpecDetect_UI_Atom | 状态 |
|--------------|------|--------------|-------------------|------|
| 0-3 | Sync | 0xEEEEEEEE | 0xEEEEEEEE | ✅ |
| 4-5 | VER | 0x0100 | 0x0100 | ✅ |
| 6-9 | STC | `int(time.time())` | `session.fscan_params['stc']` | ✅ 已修复 |
| 10-17 | TS | `_get_streamsrc_timestamp()` | `_get_streamsrc_timestamp()` | ✅ |
| 18-19 | Indicator | Band1=0x0026, Band2=0x0126, Band3=0x0168 | 相同 | ✅ |
| 20-23 | FSCAN_type | 0x04000000 | 0x04000000 | ✅ |
| 24 | DT | 12 (FSCAN) | 12 | ✅ |
| 25-28 | DL | 1057 | 计算值 | ✅ |
| 29-61 | metadata | Band专用33字节 | Band专用33字节 | ✅ |
| **50** | **start_index** | **metadata[21]=start_index** | **metadata[21]=start_index** | ✅ 已修复 |
| 62+ | spectrum | [dBm][FF]交替 | [dBm][FF]交替 | ✅ |

### 关键差异点

| # | 项目 | emulated_atom | SpecDetect_UI_Atom | 影响 |
|---|------|--------------|-------------------|------|
| 1 | RMCP请求nFlags | 1 (固定) | func_id (15) | 待验证 |
| 2 | parse_fscan返回值 | dBm值 (level/10) | RAW int16 | 无 (encode内部转换) |
| 3 | encode处理 | 直接用dBm | 内部level/10转dBm | 结果相同 |
| 4 | STC | 动态值 | 固定0 | 待验证是否影响 |
| 5 | metadata offset 50 | `struct.pack_into('<H', frame, 50, start_index)` | `struct.pack_into('<H', metadata, 21, band)` | 效果相同 |

### metadata[21] / frame[50] 详解

emulated_atom 中 frame[50] 对应的是 metadata 的 offset 21:
```
frame[29-61] = metadata (33 bytes)
frame[29+21] = frame[50] = metadata[21] = start_index (little-endian uint16)
```

Band1 start_index=0, Band2=512, Band3=1024

这个值用于告诉客户端当前帧覆盖的频率范围起点。

## 模板 Header 优化 (2026-04-19 傍晚)

### 讨论

**观察**: 所有成功响应的 Header 结构完全相同，只是 `bizResText` 变化

| 场景 | bizResCd | bizResText |
|------|----------|------------|
| 成功 | BIZ-000001 | 调用成功 |
| 失败 | BIZ-000001 | 调用失败 |

**决定**:
- Header 也用占位符 `{bizrescd}` 和 `{bizrestext}`
- 中文原文替代 HTML 实体 `&#x...;`
- 移除 fallback 硬编码，依赖模板

### 修改

**提交**:
| 提交 | 内容 |
|------|------|
| `953674d` | `_envelope.xml` 使用占位符，中文原文 |
| `33292a2` | 移除 fallback 硬编码，提取 `_build_http_response()` |

**模板结构**:
```xml
<!-- _envelope.xml -->
<soapenv:Header>
    <srrc:ProviderResponse>
        <srrc:bizResCd>{bizrescd}</srrc:bizResCd>
        <srrc:bizResText>{bizrestext}</srrc:bizResText>
    </srrc:ProviderResponse>
</soapenv:Header>
```

**before**:
```python
if not self._envelope_template:
    # 硬编码 fallback
    soap_body = f'''...'''
else:
    soap_body = self._envelope_template.replace(...)
```

**after**:
```python
soap_body = self._envelope_template.replace('{body}', body)
soap_body = soap_body.replace('{bizrescd}', fields['bizrescd'])
soap_body = soap_body.replace('{bizrestext}', fields['bizrestext'])
return self._build_http_response(soap_body)
```

- [x] 模板 Header 使用占位符

- [x] 提取 `_build_http_response()` 统一方法

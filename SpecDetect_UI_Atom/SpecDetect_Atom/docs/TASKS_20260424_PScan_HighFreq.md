**解决日期**: 2026-04-24
**方案**: RMCP 4001点 (80-180MHz) 中按频率选取 [2280:3721] = 1441点 (137-173MHz)

## 已确认结论

### 1. 数据对应关系 ✅

| 数据源 | 帧数 | 数据类型 | 点数/帧 |
|--------|------|----------|---------|
| RMCP回调 | 13个 | DSCAN | 605点 |
| streamsrc发送 | 12个 | FSCAN | 1441点 |

**结论**: PScan请求后，设备返回13个DSCAN回调帧，Atom转换为12个FSCAN帧发送。

### 2. PL与Points关系公式 ✅

```
PL = 2 × points + 36
points = (PL - 36) / 2
```

| PL | points | FSCAN编号 |
|----|--------|-----------|
| 104 | 34 | #6, #9, #12 |
| 360 | 162 | #3, #10 |
| 616 | 290 | #1, #4, #7 |
| 872 | 418 | #2, #5, #8, #11 |

### 3. 1441点组成 ✅

```
┌─────────────────────────────────────────────────────────┐
│                    1441 点                             │
├─────────────────────┬─────────────────────────────────┤
│   Payload (N点)    │         Gap (1441-N点)           │
│   spectrum数据      │   前(605-N)点: RMCP数据填充     │
│                    │   后836点: 高频填充 (-88 dBm)   │
└─────────────────────┴─────────────────────────────────┘
```

| FSCAN帧 | PL | Payload | Gap | RMCP填充 | 高频填充 |
|---------|-----|---------|-----|---------|---------|
| #1,#4,#7 | 616 | 290 | 1151 | gap前315点 | 836点 |
| #2,#5,#8,#11 | 872 | 418 | 1023 | gap前187点 | 836点 |
| #3,#10 | 360 | 162 | 1279 | gap前443点 | 836点 |
| #6,#9,#12 | 104 | 34 | 1407 | gap前571点 | 836点 |

### 4. Gap高频区数据统计 ✅

**来源**: streamsrc包中gap数据直接读取（int16小端序）

| 指标 | 值 |
|------|-----|
| 均值 | 40 |
| 范围 | 16 ~ 86 |

**编码方式**: 值 - 128 = dBm
- 高频区均值: **-88 dBm** (范围 -112 ~ -42 dBm)

### 5. 帧头结构 ✅

streamsrc FSCAN帧 (DT=12, 62字节头):

| Offset | 字段 | 大小 | 说明 |
|--------|------|------|------|
| 0-3 | Sync | 4B | `EEEEEEEE` |
| 4-5 | VER | 2B | 1 |
| 6-9 | STC | 4B | 通道标识 |
| 10-17 | Timestamp | 8B | 时间戳 |
| 18-19 | Indicator | 2B | 0x0068/0168/0268/0368 |
| 20-23 | FSCAN Type | 4B | `0B000000` |
| 24 | DT | 1B | 12 (FSCAN) |
| 25 | DL | 1B | metadata+spectrum长度 |
| 26-61 | Metadata | 36B | 见下节 |
| 62+ | Spectrum | N×2B | int16小端序 |

## 实现目标

### PScan streamsrc帧生成函数

**输入**:
- RMCP DSCAN回调 (605点int16)
- PL值 (104/360/616/872)
- 高频填充值 (-88 dBm)

**输出**:
- streamsrc FSCAN帧 (DT=12, 1441点)

**组装逻辑**:
1. RMCP int16值 ÷ 10 = dBm
2. 取RMCP前N点(N由PL决定)作为spectrum
3. gap前(605-N)点填充剩余RMCP数据
4. gap后836点填充 -88 dBm
5. 调用`build_fscan_frame()`生成帧

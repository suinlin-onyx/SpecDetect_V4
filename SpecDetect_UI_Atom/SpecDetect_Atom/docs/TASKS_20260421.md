**B_MScan 分析进度** ✅ 已完成:

| 数据源 | nBdType/DT | 数据大小 | level值 | 备注 |
|--------|-------------|----------|---------|------|
| RMCP SGLFREQ | 0x0E | 31B | 398 (39.8dBm) | int16, 单位0.1dBm |
| streamsrc DT=13 | DT=13 | 45B | 39 | 调用 `build_mscan_frame(39)` |

**电平转换（已确认）**:
- RMCP level: int16，单位 0.1 dBm → 需 ÷10 得到 dBm
- streamsrc level: 偏移量43-44，2字节小端序
- **转换公式**: `dbm_level = RMCP_level // 10`

**帧结构（已确认）**:
- Real Atom 发送多个 45 字节子帧，每个以 `EEEEEEEE` 同步头开始
- `build_mscan_frame()` 创建正确格式：DT=13, DL=16, level在偏移量43-44
- PL字段值(789)与帧长度(45)不一致——PL可能是子帧数量或容器长度指示

**帧数量差异**:
- RMCP SGLFREQ 回调: 41 帧（电平 27.3-58.3 dBm）
- streamsrc DT=13 帧: 仅 3 帧（电平 39, 45, 42）
- Real Atom 只选择性转发约 7% 的 SGLFREQ 回调到 streamsrc

**streamsrc封帧格式参考 (B_FScan)**:
- DT = 12
- metadata: indicator(2B) + start_index(2B) + 帧长度(2B) + 频率范围(2B) + 频点数量(2B)
- 数据: [dBm][0xFF] 交替封装

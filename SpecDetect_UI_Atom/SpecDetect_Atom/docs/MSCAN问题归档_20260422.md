# MSCAN B_MScan 接口问题归档

**创建日期**: 2026-04-22
**最后更新**: 2026-04-25

## 问题概述

B_MScan 接口调试，test tool 接收 MSCAN 帧时：
- 频率显示 0.0000MHz（应为 100MHz）
- 电平显示 0（应为 -50~-30 dBm 范围）
- 推送间隔 6-7秒（真实设备约 300ms）

---

## 问题列表

### P0 (关键)

#### P0#1: MSCAN 帧 frequency 显示 0
- **现象**：test tool 解析帧显示 `频率:0.0000MHz`
- **原因**：MSCAN 帧 offset 30-37 存储了错误值
- **分析**：
  - MSCAN 帧是 45 字节
  - 帧头 24 字节 + payload 21 字节
  - payload 结构：DT(1) + DL(1) + freq_count(4) + frequency(8) + fixed(4) + level(2)
  - 原始代码 offset 30-37 固定值 `0x0001000000000000` = 281GHz
  - test tool 实际从 offset 30-33 读取 4 字节 frequency
- **修复状态**：✅ 已修复，offset 30-33 改为存储 4 字节大端 frequency

#### P0#2: 电平显示 0
- **现象**：test tool 显示 `电平:0`
- **原因**：parse_fscan_payload 解析 SGLFREQ level 位置可能不对
- **分析**：
  - RMCP SGLFREQ payload (13 bytes): `0e010001000000000000000d02`
  - n_bd_type=14 (SGLFREQ)
  - counters 在 payload[1:9] 或 payload[3:11] 位置不一致
  - level 应在 payload[11:13] = 0x020D = 525
  - 代码从 offset 11 读取 level，但可能因为 TCP 粘包导致帧偏移
- **修复状态**：❌ 待修复

#### P0#3: 推送间隔过长
- **现象**：推送间隔 6-7 秒（真实设备约 300ms）
- **原因**：
  - RMCP 接收线程中 parse_fscan_payload 返回 None 导致帧被丢弃
  - 实际上收到很多帧但大部分解析失败被跳过
  - 之前修改让 parse 失败时也推送 level=0 的帧
- **修复状态**：⚠️ 部分修复，需要验证

---

### P1 (重要)

#### P1#1: SGLFREQ counters 解析位置不一致
- **现象**：代码从 payload[1:9] 解析，rmcp_proxy 从 payload[3:11] 解析
- **分析**：
  - `parse_fscan_payload` 使用 payload[1:9]
  - rmcp_proxy 的 _parse_stream_frame 使用 payload[3:11]
  - 两种解析得到不同结果
- **修复状态**：❌ 待确认正确位置

#### P1#2: RMCP 请求 frequency 格式
- **现象**：之前使用 "100MHz" 格式，后来改为 "100000000"
- **分析**：需要确认真实设备期望的格式
- **修复状态**：✅ 已修复为 Hz 数值格式

## 技术细节

### MSCAN 帧格式 (45 字节)

| Offset | 大小 | 字段 | 说明 |
|--------|------|------|------|
| 0-3 | 4 | Sync | 0xEEEEEEEE (大端) |
| 4-5 | 2 | VER | 1 (小端) |
| 6-9 | 4 | STC | 同步通道号 (小端) |
| 10-17 | 8 | TS | 时间戳 |
| 18-19 | 2 | PL | 21 (大端) |
| 20-21 | 2 | EL | 0 (大端) |
| 22-23 | 2 | PAD | 0 |
| 24 | 1 | DT | 13 |
| 25 | 1 | DL | 16 |
| 26-29 | 4 | freq_count | 1 |
| 30-33 | 4 | frequency | Hz (大端) |
| 34-37 | 4 | fixed | 0x00000001 |
| 38-41 | 4 | fixed | 0x0084D797 |
| 43-44 | 2 | level | dBm (小端) |

### SGLFREQ RMCP 帧格式 (31 字节)

| 字段 | 大小 | 说明 |
|------|------|------|
| RMCP Header | 18 | 标准 RMCP 帧头 |
| n_bd_type | 1 | 0x0E (14) |
| counters | 8 | 4 * int16 |
| level | 2 | int16 |
| (padding?) | 2? | |

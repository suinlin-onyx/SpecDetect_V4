# 生产环境 Atom XML 解析失败 [已修复]

**创建日期**: 2026-05-14
**修复完成**: 2026-05-14
**问题**: 生产环境客户端无法解析当前版本 Atom 返回的 SOAP 响应
**对比基准**: 原版 Atom (正常) vs 当前版本 Atom (异常)

---

## 问题描述

生产环境部署测试中：

- **原版 Atom**: 返回的数据客户端能正常解析
- **当前版本 Atom**: 客户端无法解析，返回乱码或解析错误

## 问题根因

| #   | 问题               | 优先级      | 根因                   | 代码位置                             |
| --- | ---------------- | -------- | -------------------- | -------------------------------- |
| 1   | 字符编码错误           | CRITICAL | XML 使用 gb2312 导致中文乱码 | `preset/device_preset.py`        |
| 2   | mfid/equid 硬编码   | HIGH     | 响应使用硬编码值而非请求中的值      | `service.py`                     |
| 3   | appid/userid 未解析 | HIGH     | parser 未解析这两个字段      | `soap/parser.py`                 |
| 4   | SOAP 命名空间缺失      | MEDIUM   | 响应缺少完整命名空间声明         | `preset/templates/_envelope.xml` |

---

## 修复内容

### P0: 字符编码修复 ✅

**修改文件**:

- `src/preset/templates/_envelope.xml` - XML 声明改为 `encoding="UTF-8"`
- `src/preset/device_preset.py`:
  - 模板加载: `encoding='gb2312'` → `encoding='utf-8'`
  - HTTP 响应: `charset=gb2312` → `charset=utf-8`

### P1: 设备信息修复 ✅

**修改文件**:

- `src/atom/soap/parser.py` - 解析列表添加 `appid`, `userid`
- `src/atom/service.py` - 所有接口使用 `params.get()` 获取设备信息:
  - `_handle_fscan()`
  - `_handle_pscan()`
  - `_handle_mscan()`
  - `_handle_sglfreqmeas()`
  - `_handle_stopmeas()`

### P2: SOAP 命名空间修复 ✅

**修改文件**:

- `src/preset/templates/_envelope.xml` - 添加完整命名空间:
  
  ```xml
  xmlns:SOAP-ENC="http://schemas.xmlsoap.org/soap/encoding/"
  xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xmlns:xsd="http://www.w3.org/2001/XMLSchema"
  xmlns:ns1="base"
  xmlns:src="http://www.srrc.org.cn"
  ```

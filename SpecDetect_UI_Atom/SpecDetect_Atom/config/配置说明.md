# 配置说明

## 配置目录结构

```
config/
├── settings.json      # 默认配置文件，会读取 xml 配置
└── legacy/            # Legacy 配置目录
    ├── atomsvcconfig.xml
    └── devinfo/       # 设备信息配置
```

## 配置优先级

**默认以 `config\legacy\` 下的配置为主。**

- `config\settings.json` 会读取 xml 配置，可不理会
- 如需使用 legacy 配置，直接修改 `config\legacy\` 下的文件即可

## 常用配置项

- `legacy/atomsvcconfig.xml` — 原子服务核心配置
- `legacy/devinfo/` — 设备信息配置（每设备一个 xml 文件）
